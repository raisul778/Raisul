# Md. Raisul Islam - Personal Portfolio Website

This folder contains a complete responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Files

- `index.html` - main website page
- `styles.css` - responsive styling
- `script.js` - mobile menu, active navigation, and reveal animation
- `assets/profile.png` - profile image from the CV
- `assets/Md_Raisul_Islam_Improved_CV.pdf` - downloadable CV

## How to run locally

Open `index.html` in any browser.

## How to deploy on GitHub Pages

1. Create a GitHub repository, for example `Raisul`.
2. Upload all files and folders from this package.
3. Go to repository `Settings` > `Pages`.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Select `main` branch and `/root` folder, then save.
6. Your live link should look similar to: `https://raisul778.github.io/Raisul/`.

## Important

Replace the GitHub and Live Demo links in `index.html` if your repository or GitHub Pages URL is different.
